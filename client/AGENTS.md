# 客户端开发规范

本文件及同目录配套文档补充[仓库公共规范](../AGENTS.md)，适用于客户端开发。
开始客户端任务前，一次性读取并遵循：

- [编码与协作规范.md](编码与协作规范.md)
- [隐式约定.md](隐式约定.md)

## 架构与体验

- 客户端使用 React DOM 和 Astryx 官方组件构建宿主工作区与独立 Web 子应用。macOS 与 iOS 入口均在 `apps/host`。
- 客户端开发遵循[客户端运行时规范](../docs/architecture/CLIENT_RUNTIME.md)，UI 开发前同时阅读
  [客户端设计规范](../docs/design/CLIENT_DESIGN.md)；资源所有权、调用与恢复规则见本目录隐式约定。
- 宿主、子应用与模板共用官方 `astryx` 技能和同一套官方组件。工作区按可用宽度支持分屏。组件缺口按客户端设计规范单独记录。
- macOS、iPhone/iPad 模拟器已接入，iOS 真机与 App Store 发行尚未验收。
  其他平台接入前必须实现对应的宿主、资源与隔离适配器。
- 当前内置设置、应用中心与 Agent 对话。宿主登录后统一向获得 `user.identity` 权限的应用提供用户身份。
  Agent 支持服务器与已授权 macOS 本地工作目录、流式消息、模型选择、取消和重试。
  Agent 开发应用尚未接入。
