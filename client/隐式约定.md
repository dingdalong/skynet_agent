# 客户端隐式约定

本文件补充[仓库公共隐式约定](../隐式约定.md)，详细机制见
[客户端运行时规范](../docs/architecture/CLIENT_RUNTIME.md)。

## 资源所有权与状态转换

- 原生 HostCore 拥有工作区、目录、权限、存储、连接、任务和进程监督；
  界面只持有可失效订阅，重载界面不关闭这些资源。
- macOS 每个子应用使用独立 JavaScriptCore 业务进程和受限 WebView。
  Actor 串行执行同步状态转移，异步效果经宿主完成后重新入队。
- 禁止 UI 自建业务 worker、直接网络访问或跨应用读取状态。
  Web worker 或 React 错误边界不能宣称具有原生独立进程的隔离等级。

## 应用协作与权限

- 子应用通过 manifest、快照、命令和带 schema 的导出动作协作。
  宿主绑定真实身份、校验权限和输入输出。
- Agent 未来使用同一套动作接口串联应用，不通过 UI 自动化执行业务。
- 内置 Agent 的目录与新服务器授权由原生宿主校验，普通子应用不能复用该权限。

## 应用包与恢复

- 应用包只含 Web 资源和业务 JS，不含原生扩展。安装或更新必须验证清单、路径、摘要、大小、
  权限和运行时；失败保留旧包及数据，禁止自动重放有副作用的任务。
- iOS 仅运行随包交付的可信内置应用，各自独立 JSC VM 与串行队列，明确为进程内隔离。
  不开放动态安装或本地开发执行器；系统后台关闭 VM 与连接，前台恢复快照，
  不自动重放有副作用任务。
