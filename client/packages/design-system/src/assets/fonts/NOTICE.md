# 字体来源

- Inter Variable 4.1：原作者发行的 `docs/font-files/InterVariable.woff2`。
  来源：https://github.com/rsms/inter/tree/v4.1
  授权：同目录 `Inter-LICENSE.txt`。
- JetBrains Mono Variable 2.304：原作者发行的 `fonts/variable/JetBrainsMono[wght].ttf`，
  本地文件名为 `JetBrainsMono-variable.ttf`。
  来源：https://github.com/JetBrains/JetBrainsMono/tree/v2.304
  授权：同目录 `JetBrainsMono-OFL.txt`。

字体原文件随项目打包，运行时通过本地资源加载；中文字符使用系统字体回退。
