# 客户端设计规范

Astryx 是宿主和子应用共同的设计依据。从工作区宽度和用户当前的任务出发布局。每个面板都应能回答三个问题：正在使用哪个应用、如何切换、如何与另一个应用并排。

## 主题与组件

- 颜色按表面、主次文字、分隔线、焦点和操作状态选用 Astryx 语义令牌。字号、间距、圆角和动效从同一官方主题取得。用文字或图标配合颜色表达选中、运行和错误状态。
- 宿主工作区在独立的 WebView 内使用 Astryx 官方组件。主屏幕、Dock 和拖动预览共用同尺寸的正方形图标。图标使用单层圆角，居中的星芒、齿轮、四格和立方体分别代表 Agent、设置、应用中心和扩展应用。主屏幕网格在图标下显示名称，Dock 将独立应用按钮放在同一个悬浮表面上。平台层提供窗口装饰、权限对话框、安全区、键盘避让和独立子应用视图的放置。
- 宿主、内置子应用及新应用模板直接使用锁定版本的 Astryx 官方组件、交互和预编译主题。新增界面先查官方组件、组合示例和模板。官方组件可组合覆盖时，使用该组合。禁止自建同类控件、复制组件源码或用 CSS 重画控件。[官方样式说明](https://astryx.atmeta.com/docs/styling-overview)
- 产品适配限于壁纸内容、面板几何与保活、触控和键盘可用空间、文本换行与系统减少动态效果。新增覆盖缺口时在此列明用途与官方组件的能力边界，随改动交付说明。
- 应用图稿共用左上方光源，星芒使用石墨色底板，齿轮使用银色底板。图标和 Dock 的投影使用 Astryx `Button` 和 `Card` 的 `elevation`。组件未提供图稿光照和磨砂材质，这两处在工作区局部适配。Dock 随主题变色，启用系统减少透明度时使用实色表面。

## 分屏与多平台

- 同时提供可见的分屏操作和键盘或辅助功能等效入口。并排时，用户能辨认当前活动面板，调整比例、切换面板或结束分屏。反馈展示松手后实际得到的布局。
- 根据工作区实际可用宽度排布。桌面和 iPad 宽度充足时提供分屏和比例调节，窄窗口显示当前应用，可通过后台切换。重新变宽时恢复组合和比例。
- 每个面板独立处理内容重排和滚动。宿主处理安全区和软键盘占位，触控有足够命中面积，键盘焦点始终可见。减少动态效果后仍能辨别活动面板和操作结果。

## 评审与验收

登录页采用居中卡片布局与提交前字段校验，矮屏或软键盘展开时仍可滚动访问完整表单。

每个应用在主屏幕网格或 Dock 中占一个位置。两处都支持拖动排序和跨区域移动。宿主保存应用顺序，网格按窗口宽度重新排布。拖动时相邻图标让位，松手后图标落入目标格，动效遵循减少动态效果偏好。悬停反馈贴合图标的圆角，名称在图标下方。桌面顶栏提供快捷命令搜索入口、后台应用入口和账号菜单；退出登录经过确认弹窗。全局 `⌘K` 打开 Astryx `CommandPalette` 快捷命令面板，原生工作区按浮层圆角镂空并在模态打开时压暗背景、支持点击外部关闭。

分屏选取器始终列出全部应用并提供「取消分屏」入口。并排分屏时，当前活动面板在工具栏顶部以语义色条、状态点和加粗标题区分，点击另一侧应用或工具栏即可切换焦点；拖动分隔线时显示实时比例或收起提示。后台应用页提供一键分屏、全部关闭（配 Toast 反馈）与空态引导。应用内的主页、应用名称、分屏、后台和关闭入口位于顶部工具栏。使用 Astryx Neutral 的浅深色主题。

Agent 新会话用 `ChatComposerDrawer` 在输入框上方显示工作位置和项目，组件未提供水平内缩的紧凑托盘规格，此处基于 Astryx 令牌局部适配内缩几何、浅深色细边与衔接层次。首发成功后收起选择区，在标题下显示项目。会话按项目嵌套在 `SideNav` 中，支持展开和搜索。会话列表放在应用内可折叠、可调宽的侧栏中，窄屏与分屏下收进侧边抽屉；宿主工具栏保留侧栏开关、新建会话与连接与设备状态入口。设置采用宽屏可折叠、可调宽 `SideNav`（按「个性化 / 系统」分组、支持设置项搜索与底部本机信息跳转关于）与窄屏/分屏顶栏内嵌 `TabList` 的自适应导航，宿主工具栏聚焦窗口级操作（宽屏提供侧栏开关，页内「安装应用」「刷新版本」留在对应视图页头）；外观与壁纸提供实时组合预览，动态效果标明系统偏好优先级与生效范围，应用管理提供概览统计、筛选搜索与详情 `Drawer`，关于页提供环境能力、子应用双端版本对照与一键复制诊断信息。每栏使用 Astryx `OverflowList` 按实际可用宽度将操作收进「更多」。macOS 的首栏为系统窗口按钮留位，工具栏空白处可以拖动窗口。

应用中心采用固定页头与 `TabList`（发现 / 服务管理），宿主工具栏提供刷新与管理员解锁 / 待审快捷入口。「发现」页支持多词检索与名称排序，封面网格随面板宽度从双列变为单列，点击应用卡片可在右侧 `Drawer` 查看目录信息与本地状态；封面随应用中心打包，未配图的应用显示立方体占位图标。解锁后的「服务管理」页提供运行概览、状态筛选（`ToggleButtonGroup` + `OverflowList`）、待审批提示横幅、服务详情 `Drawer`（支持一键复制镜像地址与摘要）及带确认弹窗的启停/下架与 Toast 反馈。

在实际 App 验证应用的打开、调整与恢复，覆盖宽度变化、键盘、触控、浅深色和减少动态效果。应用数据与界面生命周期遵循[客户端运行时规范](../architecture/CLIENT_RUNTIME.md)。
