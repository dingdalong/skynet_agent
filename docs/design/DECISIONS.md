# 设计决策

本文件只记录仍然生效的设计决策。变更历史由 Git 提交记录保存。

## D-001：Beautiful UI 全局视觉与平台行为分工

整个客户端及后续页面采用 Beautiful UI Vue 的设计语言，包括字体、配色、控件、表面、阴影与动效，
通过共享基础组件和 DTCG Token 统一工程实现，保留较宽松的应用密度。
Apple HIG 等宿主规范负责窗口与系统交互，WCAG 2.2 AA 是无障碍底线；不引入组件演示中的虚构业务。

## D-002：桌面与移动端分别统一体验

macOS、Windows、Linux 桌面 App 与桌面 Web 共享界面和交互规则；相同内容区域尺寸、主题及
状态下保持一致。移动 App 与移动 Web 共享移动布局。窗口、系统菜单、快捷键、返回手势和
安全区按宿主能力适配，不改变共用业务流程。

## D-003：不打包 Apple 专属资源

跨平台统一使用本地 Inter 和 JetBrains Mono，中文使用系统字体回退；项目不嵌入或跨平台分发
SF Pro、SF Symbols、Apple UI Kit 和 Apple 品牌图形。图标统一使用 Lucide。

## D-004：规范与代码同步变更

MVP 发现规范问题时，必须基于可复现证据同时修改文档、Token、Storybook、组件和测试。
禁止在单个页面加入绕过规范的一次性样式。

## D-005：本地能力最小授权

macOS、Linux 桌面可承载 bash、PTY 和补丁执行，目录由该桌面用户选择。
Agent、权限规则和独立权限模型继续由服务器管理，共用 C 核心执行沙盒和工具。
桌面默认关闭远程，用户手动开启后同用户名设备可继续已绑定会话；开关持久保存，关闭停止远程任务。
Web、移动端和 Windows 首期不承载本地执行。沿用用户名登录，不新增账号认证或配对。

## D-006：MVP 视觉验证进入规范门槛

可访问性不能只按 Token 的静态值验收。MVP 实际渲染时发现，强调色与 soft 背景组合、次级
标签在侧栏背景上的对比度不足；因此新增对比度修正和渲染态检查要求，并调整了相关语义色。

错误重试必须从失败请求对应用户消息恢复内容，并校验重试会产生新请求。可选提示区域退出
布局时不得破坏 Grid 行分配；这些要求已同步到组件和无障碍规范。
