# Agent 交互模式

## 数据边界

会话、消息、模型上下文和生成任务归服务器上的 user 所有，以用户名识别用户。
同名用户的多个客户端共享会话与消息；每个页面独立选择会话和编辑草稿。
刷新、断线和退出不删除数据或停止生成，重新连接自动恢复；服务器重启后数据清空。
用户名保存在本地。App 的草稿和会话选择保存在 Rust 核心内存，页面重载后恢复，退出 App 后清空；
Web 的会话选择保存在当前页面的 sessionStorage，草稿仅保留页面内存。

客户端不得直接调用模型供应商。所有模型请求通过 Skynet 网关完成，避免密钥进入浏览器、
本地存储或 Tauri 配置。

## 流式回答

用户发送消息后立即显示用户消息和运行状态。首个增量到达前超过 1 秒可显示“正在思考”，
首个文本到达后停止该提示并持续追加内容。

主模型返回的思考保存在助手消息中，权限模型返回的思考保存在对应工具记录中，两者都流式回传，
默认折叠。展开后展示实际模型名称和思考状态；取消与失败保留已接收内容，重连和重载从快照恢复。

输入栏按会话选择服务器提供的模型，默认 Flash，可切换 Pro。切换从下一次模型请求开始生效，
已经发出的请求使用原配置继续完成。权限模型默认跟随当前选择，也可由服务器固定；页面显示实际使用的模型。

屏幕阅读器播报开始生成、正在停止和完成状态，避免逐 token 播报。滚动仅在用户位于底部时自动跟随；
用户向上阅读时保留位置并显示“回到最新消息”。

## 取消

运行中显示“停止”按钮。取消请求得到确认后维持“正在停止”，模型与工具退出、历史检查点保存和占用
释放后，收到该任务的取消终态推送才允许继续发送。取消后保留已输出文本，并标记“已停止”。
已有模型响应流会主动关闭；建立连接或等待响应头期间先标记取消，取得流后立即释放。

## 失败与重试

请求失败时：

1. 保留用户输入；
2. 显示面向用户的错误和是否可重试；
3. 不把模型密钥、供应商错误响应体或堆栈展示给用户；
4. 重试创建新的请求；未执行工具时不复用半截回答，已执行工具时从保留的结果继续，不重复副作用。

失败记录和重试信息绑定原会话及原用户消息。切换会话不携带其他会话的错误或重试入口；返回
原会话后可以继续重试。重试只替换对应的失败回答，不重复插入用户消息。发送新的消息后，
旧失败记录仍保留，但只提供最近一次失败请求的重试入口。

## 会话

新建时优先复用当前空会话，或切换到该用户已有的空会话；只有没有空会话时才创建。
空会话以没有展示消息为准，草稿保留；失败或停止的对话不作为空会话复用。
会话标题来自最近一条用户消息并做长度限制。切换会话必须保留各自的消息历史与草稿。
每个会话只能运行一条生成，不同会话可以并发。任意在线端均可停止同一用户的任务。
新建会话等待期间暂停输入，避免草稿写入即将离开的会话。暂不提供删除、搜索或密码认证。

各端按会话独立保存草稿，新会话从空草稿开始。断线保留展示，重连以用户快照更新消息并保留
本端未发送草稿。App 重载后继续订阅 Rust 核心的缓存和生成状态；Web 重载后恢复服务器消息和
失败状态，草稿从空白开始。

## 消息展示与主题

消息通过左右位置、头像和气泡样式区分用户与助手，不重复显示“你”或“Agent”角色文字；
屏幕阅读器仍能识别消息角色，生成、停止和失败状态继续显示。

首次使用跟随系统主题；主题按钮每次点击都切换当前实际明暗状态，并保存明确的浅色或深色偏好。
桌面 App、桌面 Web、移动 App 和移动 Web 使用同一切换行为。

## 工具过程

工具在服务端执行，使用 Beautiful UI Vue 的中性表面、轻边框、圆角及细阴影融入助手消息。
折叠摘要显示工具名称和状态，展开显示命令或补丁、工作目录、权限范围、判断原因及输出。
状态使用“正在判断权限”“正在执行”“已阻止”“已完成”“执行失败”“已停止”，同时提供文字与图形语义。
权限由服务端规则和独立 LLM 决定，客户端不提供人工审批入口。

工具输出只作为文本呈现，不执行 HTML、脚本或终端控制序列。输出截断与非零退出码明确展示。
状态更新保留用户展开与阅读位置，不逐字符播报；键盘可以展开卡片，明暗主题和移动布局复用共享 Token。
取消和失败保留已经完成的文件修改与工具记录，工作文件不会随服务器聊天内存清空而自动删除。

## 本地操作

MVP 不执行本地命令。未来本地操作必须：

- 由云端生成结构化请求，不使用自由文本 shell 命令；
- 在客户端展示动作、参数、目标路径和影响范围；
- 获得用户明确确认；
- 通过 Tauri 权限白名单执行；
- 返回结构化结果，并允许用户撤销可撤销的操作。
