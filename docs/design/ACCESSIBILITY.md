# 无障碍规范

## 基线

所有界面以 WCAG 2.2 AA 为最低要求，同时遵循 Apple HIG 的平台语义。每项组件验收至少覆盖：

- 普通文字对比度 4.5:1；
- 大号文字、图标和界面边界对比度 3:1；
- 小字号文字即使位于 soft 状态背景上，也按普通文字 4.5:1 验收；
- 2px 以上可见焦点环；
- 所有操作可仅用键盘完成；
- 不使用颜色作为唯一状态表达；
- 支持 200% 文字缩放且不丢失内容；
- 支持 `prefers-reduced-motion`；
- 输入框有可见标签和明确错误关联；
- 浮层关闭后焦点返回触发元素；
- 固定区域不能完全遮挡当前焦点。

## 键盘

Tab 顺序与视觉顺序一致。禁止在自定义控件中形成键盘陷阱。图标按钮必须有名称；菜单、
对话框和抽屉使用成熟的语义原语管理焦点。

## 屏幕阅读器

装饰性图标设置 `aria-hidden="true"`。流式回答使用礼貌播报并合并高频更新。状态数变化
播报完整含义，例如“3 个会话”，而不是只播报数字。

## 动效

减少动效开启时：

- 删除位移、缩放、弹跳和循环装饰动画；
- 保留 0 至 100ms 的必要反馈；
- 页面和浮层直接切换到最终状态；
- 不依赖动画结束事件更新业务状态。

## 触控

主要操作视觉和可点击区域至少 44×44 CSS px，Android 发布版本至少 48dp。相邻操作至少保留
8px 间距。滑动操作必须同时提供可见按钮或菜单替代。

## 验收

- `axe-core` 无 serious 或 critical 问题；
- 自动化对比度检查覆盖每个语义文字/背景组合；静态 Token 值不能替代渲染结果检查；
- Storybook 和 Playwright 覆盖键盘焦点、错误、加载和减少动效；
- 浅色、深色和高对比度分别验证；
- 1440×900、1024×768、390×844 三种视口无横向滚动或被遮挡焦点。
