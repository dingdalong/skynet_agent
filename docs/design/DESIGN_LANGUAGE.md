# Skynet Agent 设计语言

## 权威来源

整个客户端以 Beautiful UI Vue 为统一视觉参照，采用轻边框、中性表面、克制的操作层级、细阴影与圆角控件。
共享 Token 管理颜色、尺寸和状态；窗口、菜单、快捷键及安全区继续遵循宿主平台规范。
Apple Human Interface Guidelines（HIG）用于平台行为与可访问交互参考：

- [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)
- [Apple Design Resources](https://developer.apple.com/design/resources/)
- [Design Tokens Community Group](https://www.designtokens.org/)
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

W3C DTCG 格式负责设计变量的工程表达，WCAG 2.2 AA 是无障碍底线。Google PAIR 和
Microsoft HAX 只用于补充 Agent 的解释、纠错、授权和自动化边界，不提供独立的视觉语言。
Fluent 2、Material 只用于核对 Windows 和 Android 的宿主交互习惯，不提供另一套页面视觉。
后续新增页面与组件继续使用同一共享设计系统。

Apple HIG 是参照来源，不是品牌替代品。项目不复制 Apple 商标、应用图标、截图或整套界面，
不使用 Apple 名称暗示官方关联。

## 设计原则

1. 内容优先：消息、任务状态和用户输入占据视觉中心，界面装饰不与应用内容竞争。
2. 层级清晰：优先通过字号、字重、留白和位置建立层级，不依赖高饱和色块。
3. 克制材质：默认使用不透明表面、轻边框和低频阴影；模糊只用于侧栏、标题栏和浮层。
4. 直接反馈：点击、发送、流式输出、取消和失败都必须在 100ms 内出现可感知反馈。
5. 一致而有平台感：品牌、布局和组件保持一致，窗口、快捷键、菜单、返回手势遵循平台。
6. 可访问：键盘、触摸、屏幕阅读器、高对比度、文字缩放和减少动效都不是后续补丁。
7. Agent 可控：明确区分生成中、已完成、失败和等待授权；不隐藏自动执行。

## 视觉基础

### 颜色

颜色按三层组织：

```text
primitive（原始色） → semantic（用途） → component（组件）
```

业务组件只能使用语义 Token 或组件 Token。浅色与深色分别验证对比度，不能简单反转颜色。
主操作使用随主题反转的中性实色；蓝色用于链接和特定强调。常规消息使用中性表面，
可读性优先于演示页面的低对比度灰色。主操作色与强调色使用独立语义 Token。

状态不能只靠颜色表达。成功、警告、失败和运行中必须同时提供图标或文字。

### 排版

普通界面使用本地打包的 Inter，代码、计时和等宽信息使用 JetBrains Mono，中文使用系统字体回退。
字体和授权文件统一位于设计系统，Web、App 与 Storybook 使用同一样式入口，运行时不依赖字体 CDN。

保留较宽松的应用密度：桌面正文约 15–16px，常规按钮约 40px；移动端正文不低于 16px，
触控操作保留足够的命中区域。长文本行宽约 60 至 72 个字符，尺寸使用 `rem`，支持 200% 文字缩放。

### 间距与形状

间距采用 4px 基础节奏。常用间距为 4、8、12、16、24、32、48px。控件圆角以 8px 和
10px 为主，卡片和大容器使用 14px 至 20px，不混用任意圆角。

### 材质

默认表面不透明。半透明和背景模糊只允许用于：

- macOS 侧栏和可拖拽标题栏；
- 移动端临时抽屉或表单页；
- 必须隔离后方内容的模态浮层。

禁止在消息卡片、输入框和主要内容区域叠加装饰性毛玻璃。

### 动效

动效只表达状态变化和空间关系。悬停与按下反馈约 120–150ms，浮层进入约 240ms、退出约 180ms。
颜色与阴影使用短过渡，位移动效只动画 `opacity` 和 `transform`，不阻塞输入。系统开启“减少动态效果”后，取消位移、缩放和循环动画，
保留即时状态切换。

## Agent 视觉语义

- 运行中：显示轻量活动指示和可取消操作，不遮挡已经输出的内容。
- 已取消：保留已收到文本，标记“已停止”，允许重新发送。
- 失败：说明原因，保留用户输入，提供重试。
- 等待授权：明确展示将执行的本地操作、目标范围和拒绝入口。
- 不确定：直接说明缺失信息或限制，不用模糊动画掩盖等待。

配色、排版和组件细节以 `design-system` 中的规范与 Storybook 样例为准。出现冲突时，
跨平台约定、WCAG 和本文件优先于组件的演示行为；视觉保持 Beautiful UI 风格。
