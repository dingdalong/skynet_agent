# 跨平台适配矩阵

## 核心策略

macOS、Windows、Linux 桌面 App 与桌面 Web 共享 Vue 组件、布局和业务交互；相同内容区域
尺寸、主题及状态下保持一致。移动 App 与移动 Web 统一采用移动版布局，横屏、大屏和浏览器
桌面模式仍保留移动导航。平台适配层只负责必要的窗口、系统菜单、快捷键和安全区能力。

| 能力     | 桌面 Web       | macOS              | Windows / Linux  | 移动 App / 移动 Web |
| -------- | -------------- | ------------------ | ---------------- | ------------------- |
| 应用外壳 | 浏览器         | Tauri 原生窗口     | Tauri 原生窗口   | 原生应用或浏览器    |
| 窗口控制 | 浏览器         | 原生红绿灯         | 系统标题栏按钮   | 系统状态栏          |
| 主导航   | 侧栏/抽屉      | 侧栏/抽屉          | 侧栏/抽屉        | 单栏 + 抽屉         |
| 主要输入 | 键盘、鼠标     | 键盘、鼠标、触控板 | 键盘、鼠标、触控 | 触摸、键盘          |
| 安全区   | 不适用         | 原生标题栏         | 原生标题栏       | `safe-area-inset-*` |
| 主题     | 跟随系统或手动 | 跟随系统或手动     | 跟随系统或手动   | 跟随系统或手动      |

WCAG 2.2 的 24px 是最低指针目标；本项目所有主要操作仍按 44px 设计，移动端按 48dp 处理。

## 窗口与标题栏

- macOS 使用原生红绿灯和可拖拽标题区域，不能用网页按钮伪造窗口控制。
- Windows 使用系统标题栏按钮和系统菜单；后续如采用自定义标题栏，必须保留原生拖拽、
  双击最大化、贴边布局和系统菜单。
- Linux 使用桌面环境提供的原生窗口控制，不另建一套业务界面。
- Web 保留浏览器地址栏和快捷键，不模拟 macOS 窗口。
- iOS 和 Android 使用系统状态栏、导航栏以及安全区，不隐藏系统返回能力。

## 键盘与快捷键

- `Enter` 发送消息，`Shift+Enter` 换行；输入法组合期间不得发送。
- `Escape` 优先关闭浮层；没有浮层时停止正在生成的回答，输入法组合期间不处理该快捷键。
- macOS App 与 macOS 浏览器使用 `Command` 语义，Windows / Linux App 与对应浏览器使用 `Control` 语义。
- App 不显示 Reload 菜单，保留原生复制、粘贴和文本操作；内部重载与开发工具重载可以使用，
  页面恢复后继续使用 Rust 核心中的连接和状态。Web 保留浏览器原生刷新。
- 所有仅图标按钮必须有可访问名称和键盘焦点。

## 数据同步与恢复

App 与 Web 共用界面和数据层接口，数据变化通过 WebSocket 自动同步；首次连接、真实断线恢复
和版本缺口由各自的数据层建立快照基线。

App 的 Rust 核心持有连接、登录状态、请求编号、会话缓存及本地视图状态。页面重载只重建订阅，
不重新登录、不重放发送命令。草稿和会话选择按窗口保存在核心内存中，退出 App 后清空。
Web 的连接和草稿保持页面生命周期，浏览器刷新会重建连接并恢复服务器数据。

## 响应式布局

- 桌面 App 与桌面 Web 使用同一宽度断点：宽屏为会话栏、消息区、上下文栏三栏布局；
  窄屏的会话栏和上下文栏均改为可关闭抽屉，消息区保持主视线。
- 移动 App 与移动 Web 始终为单栏 + 抽屉布局，输入区位于安全区上方，次要信息按需展开。
- 不以 Web / Tauri 宿主类型决定桌面或移动布局；移动设备识别需覆盖 iPadOS 桌面模式。

浏览器缩放至 200% 或系统文字放大时，三栏布局应提前降级，不能依赖固定像素宽度。

## 验证频率

验收层级、本次任务端到端覆盖及测试产物管理统一遵循
[编码与协作规范](../../编码与协作规范.md#测试用例)。首次支持新平台及发布时，另需满足以下平台扩展门槛。

## 平台扩展门槛

当前优先验证 macOS App 与 Web。Windows、Linux、iOS、Android 开发和发布前必须分别验证：

1. 原生窗口、状态栏、返回和后台恢复行为；
2. 鼠标、键盘、触摸和屏幕阅读器；
3. 浅色、深色、高对比度和减少动效；
4. 安全区、虚拟键盘、横屏和 200% 文字缩放；
5. 平台打包、签名和更新路径。
